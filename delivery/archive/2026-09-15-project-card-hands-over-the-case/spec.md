# Spec: карточка проекта отдаёт кейс и не дёргается при смене шага

## Problem

Два замечания владельца по одному экрану, 15.09.2026.

**Файл кейса с карточки забрать нельзя.** Человек, разобравшийся здесь, почему
группа именно такая, уходит искать тот же проект в таблице «Кейсы». Ответ есть,
но не там, где возникает вопрос.

**Смена шага кривой бросает страницу наверх, а кривые меняются рывком.** Причина
одна: со сменой шага меняется ключ запроса, `charts.data` становится
`undefined`, и блок «Динамика» снимается целиком — вместе с переключателем,
который только что нажали. Страница схлопывается на высоту строки «Рисуем
кривые…», и браузер прижимает прокрутку к верху.

## In scope

- `GET /api/cases?project_id=<id>` — библиотека, суженная до одного проекта.
- Кнопка «Скачать PDF» на карточке проекта; выключена с названной причиной,
  когда качать нечего.
- Прежние кривые остаются на экране, пока едут новые; переключатель не
  исчезает; подмена показана приглушением.
- `GET /api/cases/selection/download?ids=…` — выборка кейсов одним архивом
  (нужна следующей поставке, живёт в том же файле).

## Out of scope

- **Сборка кейса с карточки.** Сборка идёт пачкой по текущим вердиктам одним
  прогоном с замком на второй одновременный; вторая дверь на фронте стала бы
  второй дверью к расходу units.
- **Шаг кривой в адресе.** Он не состояние экрана, а поза для разглядывания:
  переживать F5 ему незачем (ср. L161).
- **Анимация самих кривых.** SVG приходит готовым с бэкенда и меняется целиком.

## Acceptance examples

| # | Вход | Ожидаемый выход |
|---|---|---|
| E1 | у проекта есть кейс с файлом | кнопка доступна, файл скачивается |
| E2 | карточка спрашивает кейс | запрос идёт с `project_id`, а не перебором библиотеки |
| E3 | кейса у проекта нет | кнопка выключена, сказано «кейс ещё не собран» |
| E4 | кейс есть, файла нет | кнопка выключена, причина ДРУГАЯ и названа |
| E5 | нажат «квартал», ответ ещё не пришёл | прежние кривые на месте, «Рисуем кривые…» не появляется |
| E6 | то же | переключатель месяц/квартал/год на месте |
| E7 | то же | блок приглушён; после ответа приглушение снято |
| E8 | выборка из одного кейса | 200, архив |
| E9 | в выборке есть несуществующий номер | 404, и номер назван |
| E10 | путь `/api/cases/selection/download` | не разбирается как номер кейса |

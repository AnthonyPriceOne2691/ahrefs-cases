# Decisions

Одна строка на выбор. Три части обязательны: **что выбрано**, **вместо чего**,
**потому что**.

- 2026-09-14 · выбрал адрес страницы для состояния 3 экранов (`app/screenState.ts`) вместо памяти вкладки (`sessionStorage`) — потому что адрес делает даром ещё две вещи: «назад» возвращает к тому, что человек видел, и ссылку на отфильтрованный список можно переслать коллеге; память вкладки не умеет ни того, ни другого
- 2026-09-14 · выбрал состояние компонента источником, а адрес — его копией, вместо чтения адреса на каждом рендере — потому что экран перерисовывается раньше, чем маршрутизатор довозит новый адрес: 6 тестов краснели на том, что панель оставалась свёрнутой, а тумблер версий не доезжал до запроса
- 2026-09-14 · выбрал правку адреса пачкой (`ScreenState.set` одним вызовом на 2 параметра сразу) вместо отдельных вызовов — потому что смена фильтра сбрасывает страницу, и второй вызов читал бы параметры такими, какими они были до первого, то есть стирал бы сам фильтр
- 2026-09-14 · выбрал `replace: true` вместо добавления записи в историю — потому что иначе «назад» разбирает историю фильтров по шагу вместо возврата на прошлый экран: 4 клика по чипам — 4 нажатия «назад»
- 2026-09-14 · выбрал память меню в состоянии оболочки (`useVisited` в `Shell`, 7 разделов) вместо ссылок на голый путь — потому что переход «Проекты → Кейсы → Проекты» иначе сбрасывал бы фильтры, хотя человек из раздела никуда не уходил
- 2026-09-14 · выбрал чистый адрес перед каждым тестом (`beforeEach` в `test/setup.ts`) вместо правки 14 файлов тестов по отдельности — потому что `window.location` в jsdom один на файл, и отфильтровавший тест оставлял соседу свои параметры: экран пользователей краснел, потому что следующий тест кликал по строке, уже раскрытой предыдущим, и **сворачивал** панель
- 2026-09-14 · выбрал вынести страницу списка в общий хук (`usePagedScreen`) вместо копии в двух экранах — потому что гейт копипаста поймал ровно этот блок в 8 строк (2 clone-пары против baseline 1), а списков будет третий: скопированное «прочитать номер, положить в состояние, отразить в адресе» и есть место, где экраны расходятся молча

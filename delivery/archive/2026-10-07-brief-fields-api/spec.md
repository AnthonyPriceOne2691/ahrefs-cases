# Spec: поля брифа копирайтеру — хранение, каталог и правка (сервер)

## Problem

Команда агентства, 07.10.2026: PDF — бриф для копирайтера по шаблону кейса (K117
«Кейсохранилища»); «Ручные поля „запрос клиента“ (свободный текст) и „сложность“
(список + комментарий), дублируемые в необязательные колонки входного файла, — ок»;
«Ниша через „Тематика“ + „Тип сайта“ из списков шаблона — ок»; «Папки проекта —
ссылкой на Google Drive, доступ регулируется правами папки»; «добавьте в карточку
проекта флажок „непубличный проект / NDA“». Владелец 07.10: шкала сложности
«низкая / средняя / высокая / очень высокая» — да; списки — собрать из ТЗ, данных и
ответов команды; «дальше делай разработку по порядку».

Половину пунктов шаблона знает только специалист: в сервисе им сейчас негде жить.

## Users / stakeholders

Специалист, который вёл проект (заполняет бриф), копирайтер (читает лист), продажи,
аккаунт-менеджеры и маркетинг (читают формулировки без SEO-опыта), владелец.

## In scope

- Описание пунктов шаблона и списков значений — один модуль (`storage/brief.py`):
  22 поля в пяти разделах шаблона, у шести — колонка входного файла.
- Хранение: JSONB `projects.brief` (миграция `c0d1e2f3a4b5`), значения списков — ключами.
- `GET /api/brief-fields` — каталог для формы (право `read`).
- `PATCH /api/projects/{id}/brief` — поля и флажок NDA (`publishable` наоборот) под новым
  правом `edit_briefs`, оно у всех трёх групп и лично отбирается.
- Карточка (`GET /api/projects/{id}`) отдаёт `brief`.

## Out of scope

- Колонки входного файла и правило NDA при повторной загрузке — следующая поставка
  (2а-2): предел 800 строк.
- Форма брифа в карточке — поставка 2б (экран).
- Лист PDF по шаблону — этап 3; скриншоты — этап 4.

## Acceptance (observable)

- [ ] Каталог полей приходит с сервера по разделам шаблона, со списками.
- [ ] Специалист группы «пользователь» записывает бриф; карточка его отдаёт.
- [ ] Негодное поле не записывается, отказ называет его словами.
- [ ] Флажок NDA меняет «публиковать без названия» на карточке.

## Non-functional

- Описание полей одно на хранение, API, приём файла и лист (урок L97).
- Значения брифа в журнал не пишутся — только ключи изменённых полей.
- Отказ — словами, строкой (`HTTP_422_UNPROCESSABLE_CONTENT`, урок L57): фронт
  показывает только строковую подробность.

## Open questions

- Списки «тип услуги», «вид проекта», «срез динамики» — предложение агента до сверки с
  листом шаблона; владельцу показаны 07.10, правка — строкой в `storage/brief.py`.

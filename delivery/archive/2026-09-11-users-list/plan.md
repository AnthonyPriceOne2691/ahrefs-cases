# Plan

Класс M. Справочник прав на бэке, экран и разбор происхождения прав.

## Уроки по затронутым путям (`archive/INDEX.md`)

- **L97** — словарь, живущий в двух местах, расходится молча: таблица прав
  остаётся одна, экран спрашивает её у сервера.
- **L57/L94** — маршрут со словом объявляется выше маршрута с параметром;
  право раздела берётся из таблицы доступа ТЗ и не трогается.
- **L23** — выдать можно только то право, которое кто-то проверяет.
- **L32/L34** — состояний четыре, у пустоты свой текст.

Не применимы: **L88**, **L90**, **L95** — файлов и числовых порогов нет.

## Rejected alternatives

- **Держать список прав на фронте** — отклонено, потому что права проверяют
  роутеры по `_GROUP_RIGHTS`, и вторая таблица разошлась бы с первой в день,
  когда правят первую (L97 стоил экрану кейсов латинских названий групп).
- **Показывать только итоговые права** — отклонено, потому что «админ, у
  которого отобрали право» выглядел бы как обычный админ: причина исчезает.
- **Показывать все права с галочками «можно/нельзя»** — отклонено, потому что
  строка «нельзя, как у всех» не несёт решения, а длина строки утраивается.
- **Удаление людей** — отклонено: за учёткой тянутся прогоны и расход, и API
  этого не даёт намеренно; выключение отвечает на ту же задачу.

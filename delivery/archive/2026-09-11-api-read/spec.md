# Spec: читающие роутеры — проекты, кейсы, расход

Вторая поставка Ф5. Сервис начинает отдавать данные, которые уже умеет считать.

## Problem

Всё, что видит пользователь по ТЗ — таблица проектов с группами, карточка
проекта, библиотека кейсов и расход units, — сегодня доступно только из
командной строки. Экраны Ф6 строятся поверх этих ответов, и пока их нет,
фронтенд начинать нечего.

Отдельная ловушка: список проектов — это сотня строк сейчас и неизвестно сколько
потом. Эндпоинт, отдающий «всё», ломается ровно тогда, когда данных станет
много, и это ловит гейт `unbounded-list` — но граница нужна не гейту, а людям.

## In scope

- `GET /api/projects` — список с группой, фильтрами по группе и домену, с
  обязательной границей выдачи.
- `GET /api/projects/{id}` — карточка: поля проекта, вердикт с объяснением,
  точки А и Б, месячные ряды под графики.
- `GET /api/cases` — библиотека: версия, группа, дата сборки, имя файла.
- `GET /api/cases/{id}/download` — файл кейса.
- `GET /api/usage` — потрачено, зарезервировано, остаток и стоимость прогона.
- Все — за правом `read`, то есть за токеном.

## Out of scope

- **Запуск прогона и очередь** — следующая поставка Ф5 вместе с `POST /api/runs`
  и журналом.
- **Пороги и пересчёт** — поставка за ней: там право `edit_thresholds`.
- Пагинация «курсором» — при сотне проектов лимит и смещение честнее и проще.

## Acceptance examples

| # | Вход | Ожидаемый выход |
|---|---|---|
| E1 | `GET /api/projects` без токена | `401` |
| E2 | `GET /api/projects` с токеном пользователя | `200`: список с группой каждого проекта |
| E3 | `?group=good` | только «хорошие»; `?query=exa` — только совпадающие домены |
| E4 | `?limit=1000` | отказ валидации: граница выдачи не обходится параметром |
| E5 | карточка проекта | вердикт, объяснение по условиям, точки А и Б, ряды по месяцам |
| E6 | карточка несуществующего проекта | `404`, а не пустая карточка |
| E7 | проект без вердикта | карточка отдаётся, вердикт `null`: «не классифицирован» — это ответ |
| E8 | `GET /api/cases` | версии кейсов с датой сборки и именем файла |
| E9 | скачивание кейса | файл с правильным именем; файла нет на диске — `404`, а не пустой ответ |
| E10 | `GET /api/usage` | потрачено, зарезервировано, остаток, стоимость на 100 доменов |

## Non-functional

- Ни один читающий роутер не обращается к Ahrefs: остаток квоты берётся у
  провайдера, который в fixture-режиме отвечает без сети.
- Списки ограничены по построению: лимит с потолком, а не «сколько попросят».
- Поставка укладывается в `max_loc_diff` 800 без waiver.

## Open questions

- Карточка отдаёт ряды целиком (до 24 месяцев × несколько метрик). Если экран
  Ф6 попросит меньше, ограничение добавится там же — сейчас резать нечего.

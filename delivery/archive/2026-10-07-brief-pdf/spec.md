# Spec: PDF — бриф для копирайтера по шаблону кейса

## Problem

Команда агентства 07.10.2026: «PDF — это бриф для копирайтера, не клиентский кейс. Копирайтер по
нему пишет публичную версию. Поэтому домен в PDF показываем всегда, но добавьте в карточку проекта
флажок „непубличный проект / NDA“ — он выводится в шапке PDF как предупреждение копирайтеру»;
«Мне нужно, чтобы в файле пдф кейса были описаны все пункты из шаблона»; «Пометка „заполняет
специалист“ для пустых полей — ок»; скрины Ahrefs — полуавтомат: «готовые ссылки на отчёты с
подставленным доменом, страной и периодом»; отчёты — Overview, Organic keywords, Referring
domains; период — от 3 месяцев до старта до конца работ; страна — гео проекта, у нескольких — по
всем странам.

Сейчас PDF — одностраничный клиентский кейс: у непубличного проекта домен скрыт («сайт в нише X»),
пунктов шаблона нет, ссылок на отчёты нет.

## In scope

- PDF начинается с брифа: шапка «Бриф для копирайтера» (домен, клиент, страны, период),
  предупреждение NDA у непубличного проекта, пункты шаблона по разделам в его порядке,
  «заполняет специалист» у пустых, ссылки на отчёты Ahrefs по каждой стране.
- Затем с новой страницы — лист «Динамика» (прежний кейс), одна страница.
- Домен назван всегда; непубличность — предупреждение, а не пропуск имени.
- Запрет RU/BY проверяет и клиента, и пункты брифа.

## Out of scope

- Загрузка скриншотов и их вставка в PDF — этап 4.
- Подписи «домен скрыт» / «публиковать без названия» на экранах — следующая поставка (3б), до
  выкатки вместе.
- Имя файла («домен — Кейс vN.pdf») не меняется.

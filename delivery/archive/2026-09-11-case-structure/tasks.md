# Tasks: структура кейса

Уроки архива, применимые к диффу: L40, L32/L34, L30, L23, L13, L8, L33 — см. plan.md.

## Модель
- [x] `CaseData` с блоками ТЗ: гео, период, задача, что сделали, А → Б
- [x] `Change`: было, стало, абсолют, процент (или его отсутствие)
- [x] `CaseOutcome`: четыре исхода, а не «собрался / не собрался»
- [x] подписи метрик по-русски в одном месте

## Сборка
- [x] точки А и Б читаются из записанного вердикта, строго по форме
- [x] анонимность решается один раз: заголовок «сайт в нише X»
- [x] `work_volume` пуст → блока «что сделали» нет
- [x] «число ключей» — сумма пяти корзин и только при всех пяти
- [x] сигнал «куплено, но не в вердикте» вместо молчания
- [x] версия порогов из вердикта, а не из активного набора

## CLI
- [x] команда `cases [--domain X] [--version V]`, печать по четырём исходам
- [x] считает проекты, а не строки (L13)

## Канон
- [x] концепт «Из чего состоит кейс» с инвариантами

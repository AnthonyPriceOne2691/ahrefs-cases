# Plan

Класс M. Уроки по затронутым путям — `archive/INDEX.md`:

- **L13** (`collect/plan.py`) — исход сворачивается по проекту, число задач
  показывается отдельно: в схеме «две точки» у проекта два запроса одним
  endpoint'ом, и разбивка по задачам дала бы «проектов 3, собрано 6».
- **L22** (`collect/endpoints.py`) — цену внешнего API нельзя брать из
  документации: «сколько строк бесплатны» выводится из замеренной цены строки.
- **L21** (`config/thresholds.default.yml`) — тест не стоит на файле, которого
  в репозитории нет: окна приходят параметром, а не из порогов заказчика.
- **L9** (`collect/fixtures/generator.py`) — зерно генератора стабильно, окна
  режут ту же серию, поэтому golden-таблицы не шевельнулись.
- **L17/L19** (`classify/points.py`) — покупка четырёх месяцев вместо двух
  **не меняет** расчёт точки, и это проверено тестом.

Не применимы: **L11** (решение о продолжении по-прежнему под семафором),
**L24** (инвариант реапера не тронут), **L3** (правок игнора нет).

## Шаги

1. `collect/scheme.py` — правило, окна, разбивка.
2. `collect/plan.py` — задачи из окон, смета по задачам.
3. `collect/cache.py` — `window_is_covered`.
4. `tests/test_collect_scheme.py` — таблица примеров E1–E13.

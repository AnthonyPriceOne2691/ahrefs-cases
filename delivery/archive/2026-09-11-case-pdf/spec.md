# Spec: одностраничный кейс — HTML-шаблон и PDF

Вторая поставка Ф4. Цель фазы («первый готовый PDF») закрывается здесь: кейс
перестаёт быть структурой в памяти и становится файлом, который можно открыть.

## Problem

Структура кейса собрана, но показать её нечем. ТЗ требует PDF по одному шаблону,
с блоками «гео, период, задача, что сделали, А → Б», обязательной сноской «данные
Ahrefs — оценка» и атрибуцией строго «рост после старта работ».

Референсных кейсов от заказчика нет, и ждать их значит не двигаться: вид делаем
свой, по решению владельца от 11.09.2026 — «цветным и информативным».

Второе требование ТЗ, которое нельзя отложить до ZIP: **контент-запрет** на
упоминания России и Беларуси. Как только появляется артефакт, появляется и
обязанность проверить его перед выдачей — не доверием к шаблону, а кодом
(`delivery/CONSTITUTION.md`, раздел про стоп-лист).

## In scope

- `templates/case.html.j2` — одностраничный макет A4: цветная шапка, главный
  результат крупно, три плитки метрик, таблица А → Б, сноска и атрибуция.
- `export/html_renderer.py` — Jinja2-окружение и `CaseData` → HTML. Автоэкранирование
  включено: в кейс приходят ниша и тип услуг из клиентского файла.
- `export/pdf_renderer.py` — HTML → PDF через WeasyPrint, запись в `EXPORT_OUTPUT_DIR`.
- `cases/stoplist.py` — стоп-лист по тексту кейса **и по гео проекта**; проверка
  стоит перед выдачей артефакта и работает fail-closed.
- Команда CLI `render <домен>` — собрать кейс и положить PDF на диск.
- Зависимости `jinja2` и `weasyprint` переходят из опциональных в обязательные.

## Out of scope

- **Подсветка «что выросло сильнее» и шаблонный текст абзацами** — следующая
  поставка, вместе с программной сверкой чисел и записью `Case` в базу. Здесь
  плитки берут первые три изменения в порядке `CASE_SUBJECTS`: правило «какие
  три» — часть подачи, а не вёрстки.
- **Графики** — поставка 4. В шаблоне под них оставлен блок, который сейчас
  пуст; заглушку «здесь будет график» не рисуем — это артефакт для клиента.
- **Нейминг файлов по ТЗ и ZIP** — поставка 5. Пока имя файла техническое.
- Брендбук, PPTX, DOCX — после MVP по решению заказчика.

## Acceptance examples

| # | Вход | Ожидаемый выход |
|---|---|---|
| E1 | кейс публичного проекта | PDF на диске: начинается с `%PDF-`, одна страница, размер ненулевой |
| E2 | HTML кейса | содержит сноску «данные Ahrefs — оценка» и атрибуцию «рост после старта работ»; формулировки «благодаря работам» нет нигде |
| E3 | анонимный кейс | ни в HTML, ни в PDF, ни в имени файла нет домена: заголовок «сайт в нише X» |
| E4 | проект с гео `RU` или `BY` | артефакт **не выдаётся**: `ContentBlockedError` с названием сработавшего правила |
| E5 | ниша или тип услуг с запрещённым упоминанием | то же: стоп-лист смотрит на текст кейса, а не только на код страны |
| E6 | проверка упала с ошибкой | fail-closed: файла на диске нет вовсе — проверка идёт до записи, а не после |
| E7 | пустой `work_volume` | блока «что сделали» в PDF нет — как и в структуре |
| E8 | числа в HTML | те же, что в структуре кейса: форматирование меняет вид, но не значение |
| E9 | два рендера одного кейса | дают одинаковый HTML: шаблон детерминирован (в PDF допускается дата создания) |
| E10 | вёрстка | одна страница A4 при шести-семи метриках; таблица не рвётся между страницами |

## Non-functional

- **Ни одного обращения в сеть при рендере.** Шрифты системные, картинок из
  интернета нет: сервер агентства может быть без выхода наружу, а кейс обязан
  собираться. Проверяется падающим `httpx`, как в классификации.
- Автоэкранирование Jinja2 включено: ниша и клиент приходят из файла заказчика.
- Поставка укладывается в `max_loc_diff` 800 без waiver.

## Open questions

- Порядок слоёв `.importlinter` объявляет `cases` и `export` независимыми
  соседями, а рендер обязан знать структуру кейса. Контракт меняется здесь:
  `export` встаёт **над** `cases`.
- Палитра и правила плиток взяты из руководства по визуализации (слоты
  категориальной палитры, ink/hairline, «цвет следует за сущностью»): метрика
  получает свой цвет здесь и сохранит его на графиках поставки 4.

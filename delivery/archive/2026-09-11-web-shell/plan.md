# Plan

Класс M. Оболочка, вход, клиент API, навигация по правам.

## Уроки по затронутым путям (`archive/INDEX.md`)

- **L59** (`api/deps.py`) — доступ определяется **правом**, а не ролью: меню
  строится по списку прав из `/api/auth/me`, а не по названию группы. Иначе
  личное право (выданное поверх группы) в интерфейсе не появится.
- **L52** (`api/deps.py`) — форма проверки писалась под смену источника; на
  фронте у неё та же роль: компонент спрашивает «есть право?», а не «какая
  группа?».
- **L32/L34** — состояний больше двух: у запроса их четыре (идёт, данные,
  отказ по праву, сервис не настроен), и каждое обязано иметь свой текст.
- **L23** — умолчание стирает разницу: `401`, `403` и `503` — три разных
  действия человека, и сливать их в «ошибка» нельзя.
- **L24** — перенос чужого паттерна вместе с опорой: `AppShell`, React Query и
  раскладку берём из CRM, оформление — из local-web-agent; Tailwind не тащим,
  потому что здесь Mantine (рецепт переносится, механизм нет).

Не применимы: **L27**, **L37**, **L22** — покупок нет.

## Шаги

1. `web/src/auth/` — контекст входа: токен, `me`, выход по `401`.
2. `web/src/api/client.ts` — запрос с токеном и разбором четырёх исходов.
3. `web/src/app/AppShell.tsx` + `routes.tsx` — оболочка и маршруты.
4. `web/src/app/nav.ts` — разделы и требуемые ими права (одно место).
5. `web/src/pages/LoginPage.tsx` — вход.
6. `web/src/**/__tests__` — vitest: навигация по правам, вход, выход по `401`.

## Rejected alternatives

- **Строить меню по группе** — отклонено, потому что право может быть выдано
  лично, поверх группы (Ф5.5): меню по группе не показало бы его владельцу.
- **Прятать разделы вместо серверных проверок** — отклонено: скрытая кнопка не
  защита, а удобство; проверки на роутерах остаются и проверяются своими
  тестами.
- **Хранить токен в памяти вкладки** — отклонено, потому что перезагрузка
  страницы выбрасывала бы человека из сервиса посреди работы; цена решения
  (`localStorage` виден XSS) названа в спеке.
- **Свести отказы к одному сообщению** — отклонено: `401` ведёт на вход, `403`
  требует прав, `503` означает ненастроенный сервис. Три разных действия.

# Decisions: project-deletion-ui

- 2026-09-24 · выбрал подтверждение на месте (`card/DeleteProject.tsx`, по образцу `users/DeleteUser.tsx`) вместо модального окна `Modal` — потому что попапы Mantine в jsdom рендерятся секундами (урок L76), а необратимый шаг проверяется тестом: K1–K5 в `card.test.tsx` идут по 10–90 мс
- 2026-09-24 · выбрал итог удаления на месте карточки (`ProjectDeleted`) вместо перехода к списку с уведомлением — потому что `notifications.show` в приложении не зовёт никто, в тестах контейнер уведомлений не смонтирован, а итог «что ушло» (числа ответа `DELETE`) пропал бы через несколько секунд; ссылка «← к списку проектов» стоит в итоге
- 2026-09-24 · выбрал обёртку `ProjectCardPage` → `ProjectCard` (карточка снимается целиком после удаления) вместо флага `enabled: deleted === null` у каждого запроса — потому что вместе с карточкой снимаются и запросы вложенных блоков (`CasePdf` спрашивает `['project', id, 'case']`), а флаг пришлось бы тянуть в каждый; заодно функция страницы уложилась в предел гейта (98 строк при пределе 80 было во флаговом варианте)
- 2026-09-24 · выбрал предпросмотр по нажатию (`enabled: asked`, `staleTime: 0`) вместо запроса вместе с карточкой — потому что `GET …/deletion` читает пачку ZIP целиком (2,4 МБ на копии стенда) и считает строки по пяти таблицам, а карточку открывают все, удаляют единицы; `staleTime: 0` — числа на момент вопроса, между двумя вопросами мог пройти прогон
- 2026-09-24 · выбрал в раскрытии прогона число удалённых среди собранных («из них проектов удалено: 1») вместо строки на каждый удалённый собранный — потому что #21 убрал собранных из раскрытия (51 строка «собран» из 53 заслоняла две причины), а возвращать их ради пометки значило бы вернуть и шум; на копии стенда в прогоне 1088 — 57 собранных, из них 1 удалённый
- 2026-09-24 · выбрал в тестах карточки обёртку `fetch`, отвечающую на `/api/auth/me` поверх заглушки теста, вместо правки восьми заглушек карточки — потому что права решают только видимость кнопки удаления, а заглушкам карточки про «кто я» знать незачем; прежние 34 теста карточки прошли без правок

# Decisions

Одна строка на выбор. Три части обязательны: **что выбрано**, **вместо чего**,
**потому что**.

- 2026-10-07 · выбрал миниатюру `data:`-адресом из запроса с токеном (`fetchScreenshotImage`) вместо `blob:` — потому что `img-src 'self' data:` прода не пускает `blob:` (контроль на продакшен-сборке: отказ и запись в журнале браузера)
- 2026-10-07 · выбрал отдельный `GET /api/screenshot-rules` вместо полей в каталоге брифа — потому что правила скринов живут в их роутере (`MAX_SCREEN_BYTES`, `MAX_PER_PROJECT`), а каталог брифа сохраняет форму для старых заглушек тестов
- 2026-10-07 · выбрал ужатие в браузере только больше предела (`fitForUpload`) вместо ужатия каждого снимка — потому что сервер всё равно перекодирует, а лишнее ужатие JPEG теряло бы качество мелкого текста на скрине
- 2026-10-07 · выбрал `max_side` в правилах сервера вместо константы 2000 в `shrink.ts` — потому что копия числа расходится с первой молча (L78)
- 2026-10-07 · выбрал общую пару `ConfirmDelete` («Да, удалить» / «Отмена») вместо своей «Да, убрать» — потому что вторую копию поймал бы гейт копипаста; формулировка M65 в спеке поправлена вслед
- 2026-10-07 · выбрал блок скринов внутри `Brief` (фрагмент за его карточкой) вместо строки в `ProjectCard` — потому что `ProjectCard` стоял ровно на пределе 80 строк, а ратчет ESLint роста не пускает; по смыслу скрины — раздел брифа
- 2026-10-07 · выбрал «скринов: N» в окне удаления только при N > 0 вместо всегда — потому что у большинства проектов скринов нет, и «скринов: 0» — шум

- 2026-09-28 · выбрал ключ бакета только на запись и удаление старых копий правилом жизненного цикла бакета (60 дней, `docs/PROD.md`) вместо ротации скриптом — потому что ключ, которым сервер может удалять, отдаёт внешние копии взломщику сервера вместе с машиной; `scripts/offsite_push.sh` делает ровно один PUT и не зовёт ни DELETE, ни LIST
- 2026-09-28 · выбрал настройки в том же `.env` вместо отдельного файла — потому что `.env` сервера и так единственное место секретов (`docs/PROD.md`); скрипты хоста читают из него только свои строки, не исполняя файл
- 2026-09-28 · выбрал секреты через stdin (`curl -K -`, `gpg --passphrase-fd`) вместо аргументов — потому что машина общая, и `ps` показывает аргументы всех процессов

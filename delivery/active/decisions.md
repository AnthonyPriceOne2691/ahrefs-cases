# Decisions

Одна строка на выбор. Три части обязательны: **что выбрано**, **вместо чего**,
**потому что**.

- 2026-09-11 · выбрал отдельный одноразовый сервис миграций вместо прогона из api при старте — потому что в бою экземпляров api несколько, и каждый начал бы мигрировать базу одновременно
- 2026-09-11 · выбрал именованный том под `node_modules` контейнера вместо простого монтирования `./web` — потому что каталог машины накрывает установленное в образе, и macOS-бинарник `esbuild` в Linux-контейнере не запускается
- 2026-09-11 · выбрал `depends_on` с условиями готовности вместо простого порядка — потому что «контейнер стартовал» не значит «Postgres принимает соединения»

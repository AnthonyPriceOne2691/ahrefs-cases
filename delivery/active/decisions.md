# Decisions

Одна строка на выбор. Три части обязательны: **что выбрано**, **вместо чего**,
**потому что**.

- 2026-09-11 · выбрал один `Dockerfile` со стадиями вместо отдельного `Dockerfile.prod` — потому что иначе дев перестаёт проверять прод: общая база и системные библиотеки разъедутся незаметно, и найдёт это первая сборка на сервере
- 2026-09-11 · выбрал nginx отдельным контейнером вместо раздачи статики из FastAPI (решение владельца) — потому что раздача файлов и API в одном процессе смешивают роли, а TLS всё равно требует чего-то впереди
- 2026-09-11 · выбрал `restart: unless-stopped` вместо `always` — потому что остановленный руками контейнер не должен подниматься сам после перезагрузки сервера: иначе «выключил на время работ» перестаёт работать
- 2026-09-11 · выбрал имена переменных в компоузе вместо значений — потому что этот файл едет в git и на сервер, и боевой секрет в нём был бы опубликован

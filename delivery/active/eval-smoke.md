# Eval smoke — file-import-explains-and-refuses

Из примеров спеки. Прогон: боевая сборка ветки в Chrome по CDP против API ветки
на копии дев-базы; таблица по ссылке — через подменённый транспорт (ответы
«Google» лежат локальными CSV). Для сравнения тот же сценарий на сборке и API
`origin/main`.

# Tasks: npm-audit-brace-expansion

## Mini-spec

**Проблема.** 30.09.2026 CI на main покраснел на гейте «Vulnerable dependencies»: `npm audit` во фронте
нашёл brace-expansion (high: квадратичное время и неограниченная рекурсия при разборе фигурных скобок) и
fast-uri (moderate: нормализация регистра хоста). Код тот же, что на зелёном 6ecfce5 — вышли advisory.
Python-половина чиста: из `uv.lock` pip-audit находит 0.

**Решение.** `npm audit fix` без `--force`: патч-версии в пределах диапазонов — brace-expansion 1.1.18 →
1.1.21 и 5.0.9 → 5.0.12, fast-uri 3.1.7 → 3.1.8. Снимок гейта опущен до фактических нулей: «снимок только
тает», и старые `js_critical=1 js_high=1 js_total=10` иначе пропускали бы рост до десяти молча.

**Примеры приёмки.**
- **S1.** `npm audit` во фронте — 0 уязвимостей; в lock поднялись только три записи, патч-версии.
- **S2.** Фронт цел: vitest 218 из 218, `npm run build`, eslint.
- **S3.** CI: gates зелёный, `deps-audit: OK` со снимком из нулей.

  шумом; судья — CI, который ставит lock (там 0). Снимок снят по CI, а не по машине разработчика.

  правки кода; лечится записанной версией, а не ослаблением гейта.

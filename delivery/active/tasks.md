# Tasks: cycle-by-file-screen

## Mini-spec

**Проблема.** Картина владельца (25.09.2026): прикрепил файл → разбор и смета → «Запустить» → строка в
журнале с неактивной «Скачать кейсы» → по окончании кнопка активна. Сервер это умеет с `cycle-by-file`;
экран — нет. Прежняя первая редакция (отдельная кнопка «Довести до кейсов» по всей базе) убрана.

**Решение.** После приёма списка под отчётом — «Весь цикл по этому списку»: смета цикла по номерам проектов
файла и кнопка «Запустить» (недоступна, если не хватает units; причина — словами сметы). Строка цикла в
журнале: «цикл по файлу · шаг N», пока идёт; в колонке «Кейсы» — неактивная «Скачать кейсы», по окончании —
«Скачать N кейсов» или «кейсов нет». В раскрытии — судьбы со ступенью. «Что дальше» говорит о цикле.

**Примеры приёмки.**

- **G1.** После загрузки — смета по проектам файла (`projects=54`), «Запустить» шлёт их номера.
- **G2.** Не хватает units — «Запустить» недоступна, причина видна.
- **G3.** Строка цикла: «цикл по файлу · шаг 2» и неактивная «Скачать кейсы», пока идёт; в конце — «Скачать 1 кейс».
- **K3.** «Что дальше» у цикла: сейчас шаг N и «Скачать станет активной»; в конце — скачать или «кейсов нет».

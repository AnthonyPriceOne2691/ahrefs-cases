# Tasks: управление пользователями

Уроки архива, применимые к диффу: L24, L52, L12, L5, L21, L8, L23 — см. plan.md.

## Модель
- [ ] `users.permissions` (JSONB) и миграция с рабочим откатом
- [ ] личные права поверх групповых в одном месте

## Пароли
- [ ] генератор на `secrets`
- [ ] пароль показывается один раз и не попадает в лог
- [ ] перевыпуск: старый пароль перестаёт работать

## Роутер
- [ ] список, создание, правка, перевыпуск — за правом `manage_users`
- [ ] смена своего пароля — любому, со знанием старого
- [ ] почта уникальна: повтор — 409

## Защиты (перенос из CRM вместе с причинами)
- [ ] нельзя снять группу с последнего администратора
- [ ] нельзя выключить свою учётную запись
- [ ] неизвестное имя права отвергается

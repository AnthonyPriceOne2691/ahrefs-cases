# Tasks: объём работ — замечание

Уроки архива, применимые к диффу: **L23** (не сливать разные причины в одну),
**L32/L34** (состояний больше двух: принято, принято с замечанием, отклонено),
**L64** (на пути отказа человек обязан увидеть, что именно чинить). Не
применимы: **L53**, **L61** — выбора источника и прав здесь нет.

## Приём
- [ ] тип замечания отдельно от отказа
- [ ] текстовый объём работ не роняет строку
- [ ] отказ сильнее замечания: строка без домена отклоняется

## Показ
- [ ] CLI печатает замечания своим разделом
- [ ] API отдаёт `notices`; `rejected_rows` от них не растёт
- [ ] экран показывает замечания отдельным списком

# Spec: один раздел от списка до журнала

## Problem

Разделов было два, и работа шла через оба: «Загрузка» принимала список и
запускала прогон, «Прогоны» показывали, что вышло. Каждый отсылал к другому.

Смета стояла третьей плашкой на странице. Кнопка «Загрузить файл» была
недоступна, пока файл не выбран полем рядом. Журнал отдавал только свежие
двадцать строк без отбора, а его таблицу дёргали: трассировка в ячейке,
длинная подпись «почему», сбитое чередование фона при раскрытии.

## In scope

- Один раздел «Прогоны»: приём списка, смета, запуск, журнал.
- Смета в окне; открытое окно переживает F5 и уход с экрана; числа при
  открытии считаются заново.
- Кнопка «Загрузить файл» открывает выбор и отправляет; поле — показ имени.
- Журнал: страницы по двадцать, отбор по автору и по датам.
- Причина отказа и судьбы доменов — в раскрытии под жёлтым знаком вопроса.
- Раскрытие занимает строку во всю ширину и не двигает колонки.

## Out of scope

- **Сохранение чисел сметы между открытиями.** Устаревшая смета опаснее
  ожидания: по ней нажимают «Запустить прогон».
- **Отбор по статусу прогона.** Не просили; статусов пять, и отбор по ним
  спорит с отбором по датам за место в шапке.
- **Прежний адрес `/intake`.** Отдельного перенаправления нет: общее правило
  маршрутов уже уводит неизвестный адрес на разрешённый раздел.

## Acceptance examples

| # | Вход | Ожидаемый выход |
|---|---|---|
| E1 | меню | «Прогоны» первыми, «Загрузки» нет вовсе |
| E2 | кнопка «Загрузить файл» до выбора файла | доступна |
| E3 | файл выбран | ушёл на сервер сам, поле показывает имя и не принимает ввод |
| E4 | «Смета и запуск» | открылось окно со сметой |
| E5 | F5 при открытом окне | окно открыто, числа посчитаны заново |
| E6 | полная страница журнала | видна листалка |
| E7 | короткий журнал | листалки нет |
| E8 | отбор по автору | уехал в запрос и в адрес |
| E9 | удалённый автор | остался в отборе с пометкой |
| E10 | обе даты | уехали в запрос |
| E11 | пусто под отбором | сказано про отбор, а не «прогонов не было» |
| E12 | упавший прогон | трассировки в таблице нет, она под знаком вопроса |
| E13 | раскрытие судеб | занимает строку во всю ширину |

# Spec: бриф подставляет ещё — кто подготовил, трудности, параллельные услуги, особенности; карточка считает оставшееся (Z64)

## Problem

- Владелец 13.10.2026 после выкатки `brief-autofill` и пересборки кейсов: «мы что-то ещё можем автоматически
  заполнять?» На предложение (кто подготовил — по «вёл проект», трудности — по динамике, параллельные услуги — по
  базе, тип сайта — словарём и по главной, языки — по главной, счёт на карточке): «делай, и добавляй ещё заполненные
  пункты, которые прям сейчас можем заполнить без особой перестройки сервиса».
- Покрытие на проде 13.10 (13 проектов с кейсом, шаг `brief-coverage`): семь пунктов из 22 подставлены у всех, тип
  сайта — у 5, ещё 14 пусты у всех. «Кто вёл проект», ряды трафика, Domain Rating точек А и Б и другие проекты того же
  домена у сервиса уже есть — их можно подставлять без units.
- Словарь ниш на 57 проектах прода: «seo-инструменты», «DIY-ритейл», «ПО», «софт для разработчиков», «контент» не дают
  тип сайта; «финтех» и «ПО» — тематику.
- **Z64.** Карточка с пустым брифом пишет «пунктов для специалиста: 22» — число каталога, а не оставшееся после
  подстановки, и подставленного не показывает.

## In scope

- Четыре новых подстановки той же функцией `known_for` (лист PDF и карточка, L258), с источником в скобках, без
  units; «Пересобрать кейсы» печатает их в готовых кейсах:
  - «Кто подготовил информацию по кейсу» — «Кто вёл проект» из файла, пока бриф никто не сохранял;
  - «Трудности, которые возникли» — подсказка по купленной динамике: месячные просадки органического трафика внутри
    периода работ и падение Domain Rating от точки А к Б;
  - «Какие услуги проводились параллельно» — другие проекты того же домена в базе с другой услугой в пересекающийся
    период;
  - «Особенности проекта» — YMYL-тематика (финансы, медицина): по тематике, записанной специалистом, или по словарю.
- Словарь ниш — по нишам прода (тип сайта и тематика).
- Z64: карточка с пустым брифом называет, сколько подставил сервис и сколько осталось специалисту, и по кнопке
  показывает подставленное; строка остаётся одной (решение владельца 07.10.2026).

## Out of scope

- «Языковые версии» и тип сайта по главной странице — следующая поставка: новый запрос к сайтам клиентов с охраной от
  внутренних адресов, хранение профиля и миграция (код пишется параллельно, сюда не входит).
- Запрос клиента, цели, выполненные работы, сложность и комментарий, папка Drive, периоды 2–3 — знает только
  специалист; ускорение колонками входного файла — по отдельному слову владельца.
- «Бюджет / объём работ» — колонка `work_volume` во входном файле есть, команда её не заполняет; кода не нужно.
- «Восстановление после падения» — нужна история до старта работ, а это units.

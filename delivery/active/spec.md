# Spec: источник рядов называет вызывающий

## Problem

Живой прогон 12.09.2026 собрал пять доменов настоящими данными — 149 точек с
`source=live`. Классификация объявила «данных не хватает» по всем пяти.

Причина не в данных: у `classify_all`, `recalc`, `preview`, `diagnose` и
`build_cases` источник рядов — параметр **с умолчанием `MetricSource.FIXTURE`**,
и вызывающие его не передают. На фикстурах умолчание совпадает с истиной,
поэтому дефект невидим для всех 459 тестов.

Это третье повторение урока L53.

## In scope

- Умолчание убрано у всех, кто читает ряды: `source` — обязательный аргумент.
- Вызывающие называют источник: CLI берёт `config_source()`, API —
  `configured_source()` (спрашивает фабрику провайдера).
- Оракул на сигнатуры: `tests/test_source_is_required.py`.
- Тесты называют источник явно — 42 вызова.

## Out of scope

- Фильтр живого прогона по списку доменов (`collect` идёт по всей базе) —
  найдено тем же прогоном, но это операционная дыра, а не этот дефект.
- Обрезанная подпись значения на графике трафика — дефект вёрстки SVG.

## Acceptance examples

| # | Вход | Ожидаемый выход |
|---|---|---|
| E1 | сигнатура любой читающей ряды функции | у `source` нет умолчания |
| E2 | живой режим, собранные данные | классификация видит их, а не фикстуры |
| E3 | пересчёт и предпросмотр порогов в бою | считают по живым рядам |
| E4 | тесты на фикстурах | называют источник явно |

## Non-functional

- Поведение на фикстурах не меняется: те же вердикты, те же числа.
- Поставка укладывается в `max_loc_diff` 800 без waiver.

## Open questions

- Тот же класс умолчаний может прятаться в других слоях (экспорт, графики).
  Оракул проверяет девять функций, которые читают ряды; список расширяется
  вместе с ними.

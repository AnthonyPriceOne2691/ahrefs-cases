# Spec: бриф для копирайтера на карточке проекта (экран)

## Problem

Команда агентства 07.10.2026: ручные поля шаблона кейса заполняет специалист, «Пометка
„заполняет специалист“ для пустых полей — ок», флажок «непубличный проект / NDA» — в
карточке проекта. С #48 и #49 бриф хранится, правится через API и заполняется файлом,
но на экране его нет: заполнить и увидеть бриф человеку негде.

## In scope

- Блок «Бриф для копирайтера» на карточке: пункты шаблона по разделам, подписи
  пунктов списков, «заполняет специалист» у пустых, ссылка на папку — кликабельна.
- Строка NDA: у непубличного проекта — предупреждение копирайтеру.
- Кнопка «Заполнить бриф» — только с правом `edit_briefs`; форма: строки, абзацы,
  родные выпадающие списки, ссылка; флажок NDA; уходит только изменённое.
- Отказ сервера — его словами, форма остаётся открытой.

## Out of scope

- Лист PDF по брифу — этап 3; скриншоты — этап 4.

## Acceptance examples

| # | Вход | Ожидаемый выход |
|---|---|---|
| M28 | Карточка с брифом: тип сайта `marketplace`, запрос клиента, ссылка на Drive; языковые версии пусты | разделы шаблона; «Маркетплейс» подписью; запрос текстом; ссылка с `href`; у пустого — «заполняет специалист» |
| M29 | Проект с `publishable: false` | «Непубличный проект (NDA): домен и название клиента в тексте кейса не раскрывать.» |
| M30 | Право `edit_briefs`: «Заполнить бриф» → дописать запрос, выбрать «Сервис / SaaS», поставить NDA → «Сохранить бриф» | `PATCH` уходит с двумя изменёнными полями и `nda: true`; просмотр показывает «Сервис / SaaS» и строку NDA |
| M31 | Сервер отвечает 422 «Папка проекта на Google Drive: нужна ссылка…» | текст отказа на экране, кнопка «Сохранить бриф» на месте |
| M32 | Права только `read` | кнопки «Заполнить бриф» нет |

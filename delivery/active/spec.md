# Spec: скриншоты проекта — API загрузки, просмотра и удаления (сервер, часть 2)

## Problem

Команда агентства 07.10.2026: «Готовые ссылки на отчёты… + загрузка скрина в карточку проекта нас
устраивает». С #53 скрин знает, как храниться, но загрузить, посмотреть и убрать его нельзя, а
удаление проекта оставило бы его файлы на диске.

## In scope

- `POST /api/projects/{id}/screenshots?kind=&caption=` — сырые байты картинки под правом
  `edit_briefs`; предел 2,5 МБ; не больше 30 скринов на проект; та же картинка — 409.
- `GET /api/projects/{id}/screenshots` — список; `GET /api/screenshots/{id}/image` — картинка с
  `nosniff` и `inline`; `DELETE /api/screenshots/{id}` — строка, затем файл.
- Удаление проекта уносит каталог его скринов; предпросмотр удаления называет их число.
- Чтение тела с пределом — одно на приём списка и скрины (`api/body.py`).

## Out of scope

- Скрины в PDF — следующий PR; экран загрузки — последний.

## Acceptance examples

| # | Вход | Ожидаемый выход |
|---|---|---|
| M48 | Специалист грузит PNG 320 × 200 с видом `ahrefs` и подписью | 201; в списке одна строка; картинка — `image/png`, `nosniff`, читается как PNG; файл в каталоге проекта |
| M49 | Тело — PDF; пустое; больше предела | 415 «…PNG, JPEG или WebP», 400, 413 «…2,5 МБ…» |
| M50 | Та же картинка второй раз; предел на проект 1 и вторая картинка | 409 «…уже есть»; 409 «…уберите лишние» |
| M51 | Пользователь с личным «Нет» на `edit_briefs` | загрузка и удаление — 403; список и картинка — 200 |
| M52 | Удалить скрин | 200; список пуст; каталог пуст; картинка — 404 словами |
| M53 | Скрин у проекта; предпросмотр удаления и удаление проекта инженером | в предпросмотре `screenshots: 1`; после удаления каталога проекта нет |

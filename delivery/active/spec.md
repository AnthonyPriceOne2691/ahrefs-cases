# Spec: скрины проекта — блок в карточке (экран, часть 4)

## Problem

Команда агентства 07.10.2026: «Готовые ссылки на отчёты… + загрузка скрина в карточку проекта нас
устраивает». С #53–#55 сервер хранит скрины и печатает их в PDF-брифе, но человек может загрузить скрин
только запросом к API: в карточке нет ни загрузки, ни просмотра, ни удаления, а окно удаления проекта
не говорит, что скрины уйдут вместе с ним.

## In scope

- `GET /api/screenshot-rules` — виды скринов с подписями (`KIND_LABELS`), предел тела и предел числа на
  проект: экран берёт их у сервера, а не держит копию.
- Блок «Скрины для брифа» в карточке: миниатюры (запрос с токеном → `data:`-адрес; CSP `img-src 'self'
  data:` не пускает `blob:`), вид словами и подпись.
- Загрузка под правом `edit_briefs`: вид, подпись, кнопка «Загрузить скрин» сама открывает выбор файла и
  отправляет. Файл больше предела ужимается в браузере (длинная сторона 2000, JPEG на белом); не ужался —
  отказ словами, запрос не уходит (ответ `413` через прокси до человека не доходит). Отказ сервера —
  его словами.
- «Удалить» с подтверждением (общая пара «Да, удалить» / «Отмена»).
- Окно удаления проекта и его итог называют число скринов.

## Out of scope

- Ссылки на отчёты Ahrefs в карточке (сейчас — только в PDF) — отдельной поставкой по слову владельца.
- Выкатка — после этой поставки, вся пачка с #48 (слово владельца 07.10.2026).

## Acceptance examples

| # | Вход | Ожидаемый выход |
|---|---|---|
| M60 | `GET /api/screenshot-rules` вошедшим; без входа | 200: виды `ahrefs` «Отчёт Ahrefs» и `ai` «Видимость в ИИ», `max_bytes` 2 621 440, `max_count` 30, `max_side` 2000; без входа — 401 |
| M61 | Карточка проекта с двумя скринами; человек только с правом `read` | блок «Скрины для брифа»: две картинки с `src` вида `data:image/png;base64,…`, подписи «Отчёт Ahrefs · Обзор · Германия (DE)» и «Видимость в ИИ · ChatGPT»; кнопок «Загрузить скрин» и «Убрать» нет |
| M62 | Специалист с `edit_briefs`: вид «Видимость в ИИ», подпись «Perplexity», файл PNG | уходит `POST /api/projects/7/screenshots?kind=ai&caption=Perplexity` с файлом телом; список перечитан, новый скрин виден |
| M63 | Сервер отказал: 415 «это не картинка PNG, JPEG или WebP» | текст отказа на экране, форма на месте |
| M64 | Предел 2,5 МБ: файл 1 КБ; файл 3 МБ, ужатый до 400 КБ; файл 3 МБ, ужатый до 2,8 МБ | первый уходит как есть; второй — ужатым; третий — отказ «…больше 2,5 МБ…», запрос не уходит |
| M65 | «Удалить» у скрина, затем «Да, удалить» | уходит `DELETE /api/screenshots/{id}`; скрина в списке нет |
| M66 | Окно удаления проекта с `screenshots: 2`; итог удаления | и в окне, и в итоге — «скринов: 2» |
| M67 | Правила или список скринов пришли не той формы (заглушка отвечает карточкой) | блок говорит, что скрины не загрузились; бриф и карточка на месте |

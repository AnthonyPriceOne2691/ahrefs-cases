# Spec: страны словами, несколько стран и весь мир

## Problem

Команда агентства, 07.10.2026 (ответы на вопросы по брифу, переслал владелец):
«Да, бывают мультигео и проекты „весь мир“. Нужно принимать список кодов через
запятую (DE, AT, CH) и специальное значение „Worldwide“. В PDF — „Германия (DE),
Австрия (AT), Швейцария (CH)“ или „Весь мир“». Отдельно: «„Германия (DE)“ — ок»
— страна на экранах и в PDF словами с кодом, а не двумя буквами.

Сегодня колонка `geo` — ровно две буквы (`String(2)`), проверка — только
формой: «DE, AT» отклоняется, выдуманный `XZ` проходит и доходит до Ahrefs.
Страна уходит в запрос к Ahrefs (`collect/plan.py`), в запрет RU/BY
(`cases/stoplist.py`), в текст кейса и шапку листа, в карточку и список
проектов.

Владелец, 07.10.2026, на вопрос «по какой стране считать цифры мультигео»:
**«Первая страна списка»** — главную страну выбирает тот, кто пишет файл.

## Users / stakeholders

Сотрудники агентства, которые грузят списки и читают кейсы (в том числе продажи
и маркетинг — без SEO-опыта, поэтому страна словами); копирайтер, который
пишет по листу публичный кейс; владелец — по развилкам.

## In scope

- Справочник ISO 3166-1 alpha-2 с русскими названиями (`storage/countries.py`,
  249 кодов, названия CLDR) и формат гео (`storage/geo.py`): разбор ячейки,
  канон хранения, страна запроса к Ahrefs, подпись словами.
- Приём: одна страна, несколько через запятую (точка с запятой, косая черта,
  пробел — то же), `Worldwide` / «весь мир»; коды сверяются со справочником,
  `UK` читается как `GB`; непонятое — отказ строки с названным кодом.
- Колонка `projects.geo` шире (`String(255)`), миграция с откатом.
- Сбор: страна запроса — первая из списка; весь мир — без параметра страны.
- Запрет RU/BY проверяет каждую страну списка.
- Текст кейса и шапка листа — страны словами; у нескольких — по какой цифры.
- API: `geo_label` в строке проекта; подсказка к файлу (`listFormat.json`) — про
  новый формат.

## Out of scope

- Сумма по странам и сбор по каждой стране — отвергнуто владельцем (units × N).
- Страна в ключе купленных рядов (Z53): смена первой страны повторной загрузкой
  не перекупает данные. Записано в реестр, чинится отдельной поставкой.
- Экран — колонка «Гео» в списке проектов, шапка карточки и текст отказа
  `bad_geo`: следующая поставка `countries-on-screen` (предохранитель «не больше
  25 файлов»: с экраном поставка задевала 28). Дальше этой — сервер отдаёт
  `geo_label`, экран его пока не показывает.
- Бриф для копирайтера, ручные поля, ссылки на отчёты Ahrefs, скриншоты —
  этапы 2–4 (свои поставки).

## Acceptance (observable)

- [ ] Файл со строками «DE, AT, CH» и «Worldwide» принят; API отдаёт подпись
      «Германия (DE), Австрия (AT), Швейцария (CH)» и «Весь мир».
- [ ] Запрос к Ahrefs у мультигео — по первой стране, у всего мира — без страны.
- [ ] Выдуманный код отклоняет строку и назван в отказе.
- [ ] RU где угодно в списке не даёт выдать кейс.

| # | Вход | Ожидаемый выход |

| M3 | Ячейка `Worldwide`, `весь мир`, `ww` | канон `WW`; подпись «Весь мир»; запрос к Ahrefs без параметра `country`; строка принята |
| M4 | `XZ`, `Германия`, `DE, XZ, qq`, `RUSSIA`, `DE, Worldwide`, `,, ;`, 90 стран | отказ строки `bad_geo`; в подробностях — непонятые коды как написаны («XZ, qq»); строка не принята, соседние — да |
| M5 | `uk, ie` | канон `GB,IE`; «Великобритания (GB)» |

| M9 | Откат миграции при `DE,AT,CH` и `WW` в базе | `DE` и пустое гео (прежний код спрашивал Ahrefs без страны ровно при пустом); повторный upgrade проходит |
| M10 | Любой список кодов справочника, любой из разделителей | канон = уникальные коды в порядке появления; канон разбирается в себя; первая страна — страна запроса; у каждой страны в подписи «Название (КОД)» |

## Non-functional

- Справочник — данные в коде, без зависимости (pycountry/babel — десятки МБ).
- Одна функция разбора на все пути (урок L124): приём, сбор, кейс и экран
  читают канон через `storage.geo`.
- Подпись — с сервера; фронт стран не переводит (урок L97).

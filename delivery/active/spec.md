# Spec: отметки в библиотеке и выбор темы

## Problem

**Библиотека отдаёт по одному.** Кнопка «Скачать PDF» стоит в каждой строке, и
это всё. Отправить клиенту подборку из десяти кейсов — десять походов к таблице
и десять файлов в папке загрузок.

**Темы не выбрать.** `defaultColorScheme="auto"` — тема идёт из настройки ОС, и
сменить её из сервиса нельзя ничем.

## In scope

- Колонка отметок в таблице кейсов; «выбрать всё» считается по строкам с файлом.
- Несколько отмеченных — одним архивом; один — PDF-файлом.
- Значок темы внизу левой колонки, отдельно от списка разделов.
- Тёмные правила оформления переведены на `data-mantine-color-scheme`.
- Читаемость светлой темы там, где она нарушена (контраст светлых вариантов).

## Out of scope

- **Отметки в адресе страницы.** Список страничный, отмеченное относится к
  видимому сейчас; адрес увёз бы в закладку номера кейсов, которых в новом
  списке нет.
- **Отметки через страницы.** Выбор живёт в пределах страницы библиотеки.
- **Выключенные кнопки Mantine.** Читаются слабо в обеих темах одинаково —
  это поведение `disabled`, а не потеря светлой темы.

## Acceptance examples

| # | Вход | Ожидаемый выход |
|---|---|---|
| E1 | отмечены два кейса | уезжает архив, в запросе оба номера и только они |
| E2 | отмечен один | уезжает PDF, а не архив из одного файла |
| E3 | «выбрать всё» на странице, где у кейса нет файла | отмечены только строки с файлом, у остальной отметка выключена |
| E4 | ничего не отмечено | панели выбора нет вовсе |
| E5 | значок темы | стоит в левой колонке и НЕ внутри списка разделов |
| E6 | клик по значку | схема на `<html>` меняется, подпись значка тоже |
| E7 | перезагрузка | выбранная тема остаётся |

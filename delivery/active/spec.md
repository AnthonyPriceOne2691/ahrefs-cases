# Spec: версии порогов и предпросмотр последствий

## Problem

Пороги версионируются, и правка — это всегда новая версия. Какие версии есть,
какая действует и, главное, **что случится, если применить другую** — видно
только через API.

Предпросмотр считается тем же проходом, что и пересчёт (`verdicts.evaluate`), и
ничего не записывает: на калибровке заказчик правит порог, смотрит последствия,
спорит и правит снова. Без экрана этот цикл идёт через консоль инженера.

## In scope

- Список версий: имя, дата, заметка, отметка действующей; выбор версии
  показывает её условия в карточке сверху.
- Кнопка «Что изменится» у каждой версии: предпросмотр без записи.
- **Четыре исхода, а не два**: сменят группу (домен: было → станет), получат
  вердикт впервые, останутся в своей группе, **данных не хватает**.
- «Никто не сменит группу» говорится **зелёным только если посчитана вся база**;
  иначе — сколько посчитано из скольких, и почему остальные не посчитаны.
- Занятость кнопки на время расчёта: он идёт по всем проектам.
- Состояния: грузится, отказ сервера — у каждого свой текст.

## Out of scope

- **Правка, сохранение версии, активация, пересчёт** — поставка
  `thresholds-edit`, под правом `edit_thresholds`.
- Сравнение двух версий между собой: предпросмотр отвечает относительно
  действующих вердиктов, и на калибровке этого достаточно.
- Предпросмотр по неутверждённым цифрам (без сохранения версии): в API его нет,
  версия должна существовать.

## Acceptance examples

| # | Вход | Ожидаемый выход |
|---|---|---|
| E1 | две версии, одна активна | список, действующая помечена |
| E3 | нажали «Что изменится» | сменят группу и получат вердикт впервые — разными списками |
| E4 | проект без купленных месяцев | он в «данных не хватает», а не в «не изменится» |
| E5 | никто не двигается, база посчитана вся | зелёное «никто не сменит группу» |
| E6 | версии нет (404) | текст сервера |
| E9 | никто не двигается, посчитано 5 из 11 | не «всё спокойно», а «посчитано 5 из 11» |

## Non-functional

- Предпросмотр идёт по всей базе: кнопка занята, пока считается; клик по строке
  и клик по кнопке — разные действия (всплытие останавливается).
- Списки доменов длинные: прокрутка внутри блока, без молчаливой обрезки.
- Узкий экран: таблица прокручивается.
- Поставка укладывается в `max_loc_diff` 800 без waiver.

## Open questions

- Предпросмотр отвечает про **действующие вердикты**, а не про выбранную
  «базовую» версию. Если на калибровке понадобится «версия А против версии Б»,
  это новый вопрос к API, а не к экрану.

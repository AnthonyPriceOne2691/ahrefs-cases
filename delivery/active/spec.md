# Spec: экран «Кейсы»

## Problem

Кейс — это то, ради чего сервис существует, и единственное, что уходит клиенту.
Увидеть и забрать его из интерфейса нельзя: `/cases` показывает заглушку, хотя
API отдаёт и библиотеку, и сами файлы.

Второе: кейс анонимизированного проекта нельзя публиковать под именем домена.
Свойство записано в кейсе (`anonymized`) и в имени файла, но человек, решающий,
что отправить клиенту, сейчас узнаёт об этом, только открыв PDF.

## In scope

- Экран «Кейсы»: библиотека — домен, версия, дата сборки, статус, имя файла,
  который уйдёт клиенту.
- **Статус публикации строкой**: анонимизированный кейс помечен, и метка
  называет следствие («домен скрыт»), а не поле модели.
- Скачивание отдельного PDF **запросом с токеном**: прямая ссылка вернула бы
  `401` — авторизация у нас заголовком, не куком.
- Состояние пачки и скачивание ZIP (API готов прошлой поставкой).
- Кнопка «Пересобрать кейсы» под правом `run`: зовёт `POST /api/runs/cases`,
  называет номер прогона и ведёт в журнал.
- Состояния: грузится, пусто, отказ сервера — у каждого свой текст.

## Out of scope

- **Пересборка одного кейса.** В API этого нет: сборка идёт пачкой по текущим
  вердиктам. Кнопка на строке означала бы придуманный на ходу endpoint.
- Удаление кейсов и чистка каталога выгрузки: необратимо, решает не экран.
- Предпросмотр PDF в браузере: скачивание закрывает задачу, просмотрщик — это
  зависимость ради удобства.
- Фильтры и поиск: библиотека отдаёт свежие сверху, а кейсов десятки. Фильтр
  заводится, когда станет нужен.

## Acceptance examples

| # | Вход | Ожидаемый выход |
|---|---|---|
| E1 | три кейса в библиотеке | строки: домен, версия, дата, имя файла |
| E2 | кейс с `anonymized: true` | метка «домен скрыт», а не голый флаг |
| E3 | кейс без артефакта | кнопки скачивания нет, названа причина |
| E4 | нажали «скачать» | запрос ушёл с токеном, файл сохранён под именем сервера |
| E5 | библиотека пуста | «кейсов ещё нет» и чем это чинится |
| E6 | сервер ответил отказом | текст сервера, а не «что-то пошло не так» |
| E7 | у человека нет права `run` | кнопки пересборки нет |
| E8 | нажали «пересобрать» | показан номер прогона и путь в журнал |

## Non-functional

- Скачанный blob освобождается `revokeObjectURL` сразу после клика: иначе
  вкладка, открытая на день, копит в памяти все скачанные пачки.
- Имя файла раскодируется из `filename*=utf-8''…`: имена кириллические, и
  человек должен узнать файл в папке загрузок.
- Узкий экран: таблица прокручивается.
- Поставка укладывается в `max_loc_diff` 800 без waiver.

## Open questions

- Версии кейса живут строками рядом: пересборка добавляет версию 2, не затирая
  первую. Схлопывать их в одну строку с историей — решение на потом, когда
  пересборок станет много.

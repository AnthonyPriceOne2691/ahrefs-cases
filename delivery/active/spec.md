# Spec: бриф на карточке и в форме показывает, что сервис заполняет сам (Z64)

## Problem

- Владелец 14.10.2026: «добавь на фронте на проде список полей, которые теперь у нас автоматически заполняются, которые
  вчера делали»; на вопрос, где, — «в блоке брифа, списком».
- Владелец 14.10.2026, после «Пересобрать кейсы» (№39): «когда захожу в бриф, то там поля, которые должны быть
  заполнены автоматически, — не заполнены». Проверено чтением прода: сервер отдаёт подстановку у всех 13 карточек
  (7–8 пунктов из 22), PDF deepseek.com v3 после №39 её печатает. Не видна она на экране: пустой бриф карточка
  показывает одной строкой «Бриф ещё не заполнен — пунктов для специалиста: 22» (решение 07.10, когда подставлять было
  нечего), а форма «Заполнить бриф» открывается с пустыми полями и о подстановке молчит.
- **Z64.** Число «22» — длина каталога, а не то, что осталось специалисту (L260).

## In scope

- Каталог пунктов (`/api/brief-fields`) говорит у каждого пункта, откуда сервис заполняет его сам (`autofill`), — одним
  местом рядом с правилами подстановки; у пункта, который знает только специалист, — пусто.
- Карточка, пустой бриф: «Сервис заполняет сам, пока пункт пуст» — пункты с `autofill` по порядку шаблона: значение
  этого проекта (`brief_known`), а если его нет — серым, откуда сервис его берёт; затем «Остальные N пунктов заполняет
  специалист».
- Форма «Заполнить бриф»: у пункта с `autofill`, пока он пуст, подпись «Пусто — подставит сервис: …» — значение этого
  проекта или откуда берётся.
- Список — то, что на проде: 9 правил подстановки и подпись «Кто подготовил» (#72). Новые пункты попадают в список из
  того же места, без правки экрана.

## Out of scope

- Новые подстановки (кто подготовил по «вёл проект», трудности, параллельные услуги, YMYL) — поставка
  `brief-known-more`, PR #73, по слову владельца 13.10 остановлена.
- Языки и тип сайта по главной странице — отложено владельцем.
- Частично заполненный бриф — как сейчас: подстановка стоит в пустых пунктах таблицы с источником в скобках.
- В бриф подстановка по-прежнему не пишется (инвариант 10): форма показывает её подписью, а не значением поля.

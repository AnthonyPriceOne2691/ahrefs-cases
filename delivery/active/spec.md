# Spec: купленные ряды помнят страну — оговорка при смене (сервер)

## Problem

Z53. Точки рядов (`metric_points`) различаются проектом, метрикой, месяцем и источником — страны среди
них нет. Повторная загрузка проекта с другой первой страной (`US` → `DE`, `DE, AT` → `AT, DE`, страна →
«Весь мир») меняет подпись в карточке и на листе, а сбор считает окна купленными: цифры остаются по прежней
стране, новые месяцы докупаются уже по новой — ряд смешивается, и никто этого не видит. Тем же путём
кампания сайта по DE получала купленные месяцы его кампании по US (`collect/cache.py`, общие месяцы
кампаний).

Решение владельца 07.10.2026: **при смене страны только предупреждать** — не докупать.

## In scope

- Точка помнит страну, по которой куплена (`metric_points.country`; «весь мир» — пустая строка). Миграция
  проставляет купленным точкам первую страну их проекта; перепокупка пишет страну заново.
- Общие месяцы кампаний одного сайта переходят только между кампаниями одной страны.
- Приём: у проекта с купленными рядами сменилась первая страна — замечание `geo_changed` в его строке
  («США (US) → Германия (DE)»), проект принят и обновлён, как прежде. Экран приёма называет причину словами.
- Оговорка `geo_note` — одна на карточку (API) и лист брифа: «цифры Ahrefs — по США (US): куплены до того,
  как первой страной стала Германия (DE)»; у смешанного ряда — «часть цифр Ahrefs — по …». Текст кейса не
  обещает «цифры — по первой из стран», когда это не так.

## Out of scope

- Показ оговорки в карточке на экране — следующей поставкой вместе со сжатым пустым брифом.
- Докупка рядов при смене страны (решение владельца — не докупать). Путь к цифрам по новой стране прежний:
  удалить проект и загрузить заново или собрать с обновлением (`--refresh`).

## Acceptance examples

| # | Вход | Ожидаемый выход |
|---|---|---|
| M79 | Сбор шага 1 по проекту «DE, AT»; по проекту «Весь мир» | точки записаны со страной `DE`; у «всего мира» — пустая строка |
| M80 | Миграция на базе с точками проектов «US» и «WW» | точкам проставлены `US` и пустая строка; откат миграции убирает колонку |
| M81 | Кампания сайта куплена по US; другая кампания того же сайта — по DE; третья — по US | DE месяцев US не получает и покупает свои; третья получает общие месяцы, как прежде |
| M82 | Проект куплен по US, файл загружен снова с первой страной DE | замечание `geo_changed` в его строке, «США (US) → Германия (DE)»; проект принят, `geo` = `DE` |
| M83 | То же у проекта без купленных рядов; у проекта, где первая страна не сменилась («US» → «US, CA») | замечаний нет |
| M84 | Карточка (API) проекта из M82; проекта со смешанным рядом; проекта, где страны совпадают | `geo_note`: «цифры Ahrefs — по США (US): куплены до того, как первой страной стала Германия (DE)»; «часть цифр Ahrefs — по США (US): …»; `null` |
| M85 | Лист брифа и текст кейса проекта из M82 | в строке «ГЕО» — та же оговорка; текст кейса не говорит «цифры Ahrefs — по первой из них» |
| M86 | Перепокупка с `--refresh` по DE | точки переписаны со страной `DE`; оговорки больше нет |
| M87 | Экран приёма с замечанием `geo_changed` | причина словами: «первая страна сменилась — цифры остаются по прежней» и подробность «США (US) → Германия (DE)» |

# Spec: удалить проект кнопкой — видя, что уйдёт

## Problem

API удаления есть (поставка project-deletion-api, #23), а на экране его нет:
удалить проект может только тот, кто пишет запросы руками. Вдобавок экран
не знает трёх новых ответов API: справочник прав покажет ключ
`delete_projects` без подписи, журнал прогонов — домен удалённого проекта как
живой, карточка пачки — кнопку «Скачать ZIP», которая ответит `409`.

## Users / stakeholders

Инженеры и администраторы агентства (право `delete_projects`); все, кто
смотрит журнал прогонов и пачку кейсов.

## In scope

- Кнопка «Удалить проект» на карточке — только тем, у кого есть право по
  `/api/auth/me` (итог с личными решениями).
- Подтверждение на месте, по образцу удаления пользователя: числа из
  `GET /api/projects/{id}/deletion` — что уйдёт, что останется.
- После удаления карточка сменяется итогом с числами ответа и ссылкой к
  списку, а не упирается в `404`.
- Подпись права «удалять проекты» на экране людей.
- «(проект удалён)» у судьбы прогона с `project_deleted`.
- Карточка пачки с `outdated` говорит словами сервера, почему её нельзя
  скачать, и не предлагает скачивание.

## Out of scope

- Удаление из таблицы проектов и пакетное удаление — не просили.
- Восстановление удалённого: удаление жёсткое по решению владельца.
- Серверная часть — сделана в #23.

## Acceptance (observable)

- [ ] Без права кнопки нет; с правом — удаление проходит кнопкой с подтверждением.
- [ ] Перед удалением видно, что уйдёт и что останется.
- [ ] Удалённый проект в журнале подписан, пачка с его кейсом не предлагается к скачиванию.

## Acceptance examples

| # | Вход | Ожидаемый выход |
|---|---|---|
| PD1 | В `/me` нет `delete_projects` | На карточке нет кнопки «Удалить проект», предпросмотр не запрашивается |
| PD2 | Право есть; «Удалить проект»; предпросмотр `116 точек, 1 вердикт, 11 кейсов, files 5, run_items 4, twin 1, pack_blocked true` | Подтверждение называет: уйдут 116 точек рядов (повторная загрузка купит их заново), 1 вердикт, 11 кейсов, 5 файлов PDF; останутся 4 строки журнала прогонов; вторая кампания сайта сохранит свои данные; пачка кейсов не скачается до пересборки |
| PD3 | «Отмена» в подтверждении | Подтверждение закрыто, запроса `DELETE` не было, карточка на месте |
| PD4 | «Да, удалить» | Уходит `DELETE /api/projects/{id}`; карточка сменяется «Проект … удалён» с числами ответа и ссылкой «← к списку проектов» |
| PD5 | Сервер отказал `409` «прогон 1814 ещё идёт (running)…» | Текст сервера показан как есть, карточка и подтверждение на месте |
| PD6 | Экран людей, справочник прав с `delete_projects` | Право подписано «удалять проекты» |
| PD7 | Раскрытие прогона, судьба с `project_deleted: true` | У домена подпись «(проект удалён)»; у живой судьбы того же домена подписи нет |
| PD8 | Пачка с `outdated: "project_deleted"` и `note` сервера | Предупреждение словами `note`; «Скачать ZIP» недоступна; «Пересобрать кейсы» у права `run` на месте |

## Non-functional

- Подтверждение на месте, не всплывающим окном: попапы Mantine в jsdom
  рендерятся секундами, а необратимый шаг обязан быть проверен (урок L76).
- Тексты отказов — словами сервера (уроки L32, L34).

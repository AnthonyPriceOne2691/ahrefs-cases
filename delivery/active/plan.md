# Plan

Класс M. Компоновка графиков, эндпоинт, источник рядов из конфига.

## Уроки по затронутым путям (`archive/INDEX.md`)

- **L53** (`collect/factory.py`) — умолчание вызывающего отключает
  предохранитель: ровно этот механизм и чиним в источнике рядов.
- **L41** (`api/routers/projects.py`) — карточка показывает **записанный**
  вердикт, а не пересчитанный: окна полос берутся оттуда же.
- **L45/L46** (`export/charts.py`) — правила рисунка оплачены прогоном:
  кириллица требует явного `font-family`, `stop-opacity` гасит градиент.
  Компоновка переезжает целиком, без «улучшений» по дороге.
- **L50** — гейт длины ловит скопление работ: компоновка едет в модуль
  рисования, а не в роутер.

Не применимы: **L10**, **L23** — источников файлов и путей отказа HTTP поставка
не добавляет, кроме уже существующего `404`.

## Шаги

1. `cases/builder.py` — `_chart_series` становится публичной `chart_series`:
   ряды под кривые нужны и API, а не только сборке кейса.
2. `export/charts.py` — `curve_blocks(...)`: компоновка «два графика».
3. `export/html_renderer.py` — `charts(case)` зовёт её же.
4. `api/routers/projects.py` — `GET /{project_id}/charts`; источник рядов из
   конфига в обоих обработчиках.
5. `api/schemas.py` — `ChartBlock`.
6. `tests/test_api_charts.py` — E1–E8.

## Rejected alternatives

- **Рисовать на фронте по рядам** — отклонено решением владельца: два рисунка
  разойдутся, и клиент с сотрудником увидят разные кривые одного проекта.
- **Звать сборку кейса ради графиков** — отклонено, потому что кейс собирается
  только для «хороших» и «средних», а карточка нужна и для «плохих».
- **Оставить параметр `source` как есть** — отклонено: это L53 слово в слово,
  и сломалось бы в Ф7 на боевом ключе.
- **Отдавать данные, а не разметку** — отклонено: у фронта появилась бы вторая
  модель графика, и правило «один рисунок» перестало бы существовать.

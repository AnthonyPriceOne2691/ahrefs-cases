# Plan: screenshots-api

## Шаги

1. `api/body.py` — тело с пределом по ходу чтения; приём списка зовёт его же (гейт дублей).
2. `api/routers/screenshots.py` — список, загрузка, картинка, удаление; распаковка и запись — в потоке.
3. `api/routers/projects.py` — удаление уносит каталог скринов, предпросмотр называет их число
   (`ProjectDeletion.screenshots`).
4. Знания: `product/brief.md` (12), карта репозитория (API).

## Уроки по затронутым путям (`archive/INDEX.md`)

- **L57**, **L64** — статусы отказа — нынешние имена Starlette: `HTTP_413_CONTENT_TOO_LARGE`,
  `HTTP_415_UNSUPPORTED_MEDIA_TYPE`; отказы проверены тестом, а не только успех.
- **L212** — предел 2,5 МБ ниже 3 МБ прокси: отказ сервера дойдёт до человека, а не умрёт на прокси.
- **L210**, **L202** — удаление проекта: строки уходят каскадом, файлы — после коммита, как PDF.
- **L90** — картинку отдаёт запрос с заголовком `Authorization`, а не ссылка: экран заберёт её `fetch`.
- **L173** — маршруты-слова (`/screenshots/{id}/image`) не спорят с `{project_id}`: отдельный префикс.
- **L80**, **L148**, **L51**, **L54** — тесты API на своих строках и своём каталоге скринов.
- **L240** — в докстроках тестов номеров уроков нет.

- **L53**, **L74** — умолчаний вызывающего нет: каталог скринов берётся из `config.export.screenshots_dir`,
  предел и потолок — константы модуля, а не параметры обработчика.
- **L78**, **L221**, **L235** — не применимы: формул «не знаю», вида домена для человека и журнала
  поставка не трогает.

## Rejected alternatives

- **multipart** — отвергнуто, потому что ради одного поля пришлось бы добавить `python-multipart`, а
  приём списка уже живёт на сыром теле.
- **Ссылка на картинку с токеном в адресе** — отвергнуто, потому что адрес с токеном пишется в журналы
  nginx и uvicorn; экран берёт картинку запросом с заголовком.
- **Перекодирование в цикле событий** — отвергнуто, потому что распаковка большой картинки на секунду
  остановила бы весь API; `anyio.to_thread.run_sync`.

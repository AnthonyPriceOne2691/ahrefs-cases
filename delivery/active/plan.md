# Plan: countries-multi-geo

## Слой и место

Формат гео нужен приёму (проверить ячейку), сбору (спросить Ahrefs), кейсу и
API (назвать словами). `collect` и `intake` в import-linter — соседи одного
слоя и друг друга не видят, поэтому модуль лежит ниже обоих — в `storage`:
`storage/countries.py` (только справочник) и `storage/geo.py` (канон, разбор,
страна запроса, подпись). Правило карты репозитория: «новый модуль кладётся в
слой, которому он принадлежит по зависимостям, а не по теме».

## Шаги

1. `storage/countries.py` — 249 кодов из `iso3166.tab` (IANA tz, общественное
   достояние), названия CLDR полной формы; четыре замены короткой формой
   («США», «Южная Корея», «Гонконг», «Макао»).
2. `storage/geo.py` — `parse_geo`, `countries`, `ahrefs_country`, `label`;
   `WORLDWIDE = "WW"`, `GEO_MAX_LEN = 255`.
3. Колонка `projects.geo` → `String(GEO_MAX_LEN)`, миграция `b9c0d1e2f3a4` с
   откатом к первой стране.
4. `intake/validate._parse_geo` → `parse_geo`; отказ `bad_geo` с подробностями.
5. `collect/plan.py` — `country=ahrefs_country(project.geo)`.
6. `cases/model.CaseData.geo_label`; `narrative._where`; `stoplist` по каждой
   стране; шаблон — `case.geo_label` в шапке.
7. API `ProjectRow.geo_label`; подсказка к файлу `listFormat.json`. Экран
   (тип, таблица проектов, шапка карточки, текст отказа `bad_geo`) — следующая
   поставка `countries-on-screen`: вместе с ним поставка задевала 28 файлов при
   пределе 25.
8. Концепты: `product/intake.md` (инвариант 7), `product/case-content.md`
   (7, 7а), `engineering/collection/collection-scheme.md` (6). Реестр: Z53.

## Уроки по затронутым путям (`archive/INDEX.md`)

- **L124** — канон один: все входы гео идут через `storage.geo.parse_geo`; второй
  нормализатор не заводится ни на фронте, ни в сборе.
- **L131**, **L221** — канон для машины и имя для человека — разные величины, и
  вид для человека меняется **везде сразу**: шапка листа, текст кейса, список
  проектов, карточка. Половина экранов с кодом читалась бы правилом продукта.
- **L97** — словарь названий на фронте был бы копией, ждущей второго читателя:
  подпись приходит с сервера (`geo_label`).
- **L67**, **E6** прежней поставки — гео остаётся отказом, а не замечанием: оно
  вход запрета стран; непонятый код отклоняет строку целиком.
- **L141** — у значения, принятого до справочника, есть честное состояние
  «неизвестно»: такой код показывается как есть, а не роняет кейс.
- **L45** — шапка с длинным списком стран меряется растеризацией: шесть стран —
  лист по-прежнему одна страница (тест, а не надежда).
- **L48** — тесты кейса проверяют содержание (фразу, подпись), а не место.
- **L5**, **L12** — enum-типов миграция не трогает; откат проверен данными (M9),
  цикл upgrade → downgrade → upgrade — прежний тест A1.
- **L76**, **L90**, **L212**, **L213** — не применимы: попапов, ссылок на файлы,
  отказов прокси и выбора файла поставка не трогает.

## Риски

- Живой запрос с пустой страной: Ahrefs обязан понять отсутствие `country` как
  «все страны» — так и было при пустом гео; тест транспорта проверяет, что
  параметр не уходит пустым (M3).
- Откат миграции теряет страны после первой — цифры при этом те же: сбор
  считал по первой (M9).
- Повторная загрузка со сменой первой страны не перекупает ряды (Z53) —
  объявлено в реестре, не чинится здесь.

## Rejected alternatives

- **Сумма по странам** (сбор по каждой стране списка) — units умножаются на число
  стран; при лимите ключа 10 000 в месяц отвергнуто владельцем 07.10.2026.
- **Весь мир для мультигео** (запрос без страны при нескольких странах) — смешал бы
  целевые рынки с остальными; владелец выбрал первую страну списка.
- **`pycountry` / `babel`** — десятки МБ зависимости ради одной таблицы названий.
- **`Intl.DisplayNames` на фронте** — лист PDF собирается на сервере; второй
  справочник назвал бы страну иначе (урок L97).
- **Колонка-массив `ARRAY(String(2))`** — `geo` строкой читают сбор, кейс, CLI и
  тесты; массив менял бы тип во всех местах ради формы, которую строка с
  запятыми передаёт так же, а откат миграции стал бы сложнее.
- **Выбросить непонятый код и принять остальные** — гео вход запрета стран:
  выброшенная «Россия» обошла бы его.

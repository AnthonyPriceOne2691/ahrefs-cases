# Plan: Ф1 — скелет и контракты

## Approach

Снизу вверх: конфиг → модели и миграция → дев-окружение → каркасы API и фронта →
CI. Порядок выбран так, чтобы каждый следующий шаг проверялся предыдущим: модели
нужны миграции, миграции — базе из compose, API — конфигу и базе.

## Stack / boundaries

Стек зафиксирован в `docs/IMPLEMENTATION_V3.md` §2, здесь не переобсуждается.
Граница поставки: всё, что не бизнес-логика. Как только появляется первая функция,
считающая метрику или группу, — это уже Ф2.

## Rejected alternatives

- **SQLite на старте, Postgres потом** — отклонён: перенос стоит переписывания
  запросов и миграций, а выигрыш только в первый день. Compose поднимает postgres
  так же одной командой.
- **Начать с фронта** — отклонён: без API и моделей фронт пишется против выдумки,
  и переделка неизбежна.
- **Развернуть В1 (гейты) в начале фазы** — отклонён: на пустом репозитории первый
  прогон выходит зелёным при нуле просмотренных файлов, и контур не проходит
  собственную приёмку (AGENT_STACK §2.A′ п.1). Волна идёт в конце фазы.

## Risks

- **Модели придётся править в Ф2–Ф4.** Смягчение: миграции с первого дня, правка
  через новую ревизию, а не переписывание первой.
- **`mypy --strict` на пустом каркасе дёшев, на логике дорог.** Смягчение: включаем
  сразу — включить позже значит разгребать накопленное.
- **WeasyPrint тянет системные библиотеки.** Смягчение: в образ они кладутся уже в
  этой фазе, хотя PDF появится в Ф4 — иначе Ф4 начнётся с отладки Dockerfile.

## Rollout / migration

Нечего раскатывать: продукта нет. Деплой-канал проверяется пустым каркасом на
2–3 день (docs/CONTOUR_ROLLOUT.md), чтобы «залью на сервер» не стало сюрпризом.

## Test / eval strategy

- Тест на импорты: ядро не тянет FastAPI и RQ (это архитектурный инвариант из
  constitution, и он должен отклонять, а не жить обещанием).
- Тесты на конфиг: дефолты без `.env`, fail-fast при `live` без ключа (A4, A5).
- Тест миграции: upgrade → downgrade на пустой базе (A1).
- `GET /api/health` в трёх состояниях: база есть, базы нет (A2, A3).
- Ссылка: `delivery/active/eval-smoke.md` не заполняется — продуктовых оракулов
  на этой фазе нет, продукта нет.

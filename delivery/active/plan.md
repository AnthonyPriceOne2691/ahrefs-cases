# Plan: удалить проект кнопкой — видя, что уйдёт

Класс M, вторая из двух поставок «удаление проектов» (экран к API #23).

## Approach

1. **Кнопка и подтверждение — `pages/card/DeleteProject.tsx`**, по образцу
   `users/DeleteUser.tsx`: подтверждение на месте, а не попапом. Кнопка видна
   по `can('delete_projects')` — итог прав из `/me` (#23 перевёл его на
   `rights_of_user`). Предпросмотр запрашивается по нажатию, а не вместе с
   карточкой: карточку открывают все, удаляют единицы. Числа и слова — из
   ответа сервера, фронт их не пересчитывает.
2. **После удаления** карточка сменяется итогом (числа ответа `DELETE`) со
   ссылкой к списку; запросы карточки выключаются — иначе повторный запрос
   упёрся бы в `404` и показал бы отказ вместо итога. Список проектов
   сбрасывается из кэша, чтобы удалённый не всплыл при возврате.
3. **Подпись права** — строка в `users/rights.ts`: словарь подписей там один.
4. **Судьбы прогона** — «(проект удалён)» у строки с `project_deleted`,
   поверх раскрытия «только проблемные» из #21: берётся из `origin/main` при
   переносе ветки.
5. **Пачка** — `PackCard` по `outdated` показывает `note` сервера и выключает
   «Скачать ZIP»; кнопка пересборки остаётся — она и лечит.

  умение: числа удаления только из ответа сервера, слова отказа и пачки —
  тоже его.
- **L170** — признак без потребителя — надпись: `project_deleted` и
  `outdated` из #23 без экрана не видит никто; эта поставка — их потребитель.
- **L101, L104** — право без происхождения — половина ответа, и список прав
  сортируется по подписям: новое право получает подпись в том же словаре, а
  порядок держит `byLabel`.
- **L91** — две работы в одном компоненте: удаление живёт своим файлом, а не
  в `ProjectCardPage`.
- **L172** — блок, снятый на время загрузки, читается как мигание: итог
  удаления встаёт на место карточки целиком, а не пустотой с «загружаем».
- **L185** — подробности прогона — отдельной строкой во всю ширину: пометка
  «(проект удалён)» живёт в ячейке домена и колонок не раздвигает.
- **L200** — утверждение проверяется там, о чём оно: пометку ищем в строке
  своей судьбы, а не по всему раскрытию.
- **L204** — проверка в браузере — на боевой сборке (`vite build`), не на
  dev-сервере.
- **L13, L150** — две кампании одного сайта — два проекта: в судьбах ключ
  строки — не домен (#21), пометка — по признаку строки, а не по домену.
- **L158, L159, L210** — удаление и история: журнал сохраняет строку, экран
  называет её удалённой, а не прячет.
- **L32, L34** — отказ называет следующий шаг: `409` показывается словами
  сервера («удалите проект, когда прогон закончится»).
- **L211** — pytest только на своей копии базы (`cases_delui_tests`).
- **L48** — тест спрашивает про содержание, а не про место: подтверждение
  проверяется по числам и словам внутри своего блока (`[data-delete]`).
- **L50, L97** — разные работы — разные файлы, общий словарь — отдельно от
  компонента: удаление живёт в `card/DeleteProject.tsx`, подпись права — в
  общем `users/rights.ts`.
- **L214** — фикстура экрана имеет форму живого ответа: в K7 все исходы
  вперемешку и две кампании одного сайта, удалённая и живая.

## Rejected alternatives

- **Модальное окно подтверждения (`Modal`)** — отклонено, потому что попапы
  Mantine в jsdom рендерятся секундами (L76), а шаг необратимый и обязан быть
  проверен тестом; образец — `DeleteUser.tsx`.
- **Переход к списку проектов с уведомлением** — отклонено: `notifications`
  в приложении не используются нигде, в тестах их контейнер не смонтирован, и
  итог удаления (что ушло) исчез бы через несколько секунд, так и не
  проверенный; итог на месте карточки проверяется и читается.
- **Предпросмотр вместе с карточкой** — отклонено: `GET …/deletion` читает
  пачку ZIP целиком и считает строки по пяти таблицам, а карточку открывают
  все, удаляют единицы.
- **Кнопка удаления в таблице проектов** — не просили; один вход к
  необратимому действию проще проверить.

## Risks

- Карточка после удаления: фоновый повтор запроса упёрся бы в `404` — запросы
  карточки выключаются, как только удаление прошло.
- `/me` старого бэкенда отдавал набор группы: без #23 кнопка у человека с
  личным «Нет» была бы видна и отвечала бы `403` — поставка идёт после #23.

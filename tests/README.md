# Тесты

Пусто — тестировать пока нечего (каркас).

Политика: покрытие изменённых prod-файлов не ниже согласованного порога,
Ahrefs-транспорт тестируется на записанных фикстурах ответов, а не живым API —
живой ключ в тестах жжёт units и делает прогон нестабильным.

Что покрывать в первую очередь:
- `intake/normalize.py` — таблица «вход → канонический хост» (мусорные URL, punycode, www)
- `collect/ahrefs_transport.py` — классификация статусов, разбор units-headers, backoff
- `classify/points.py` + `deltas.py` — расчёт А/Б на сериях с дырами и выбросами
- `classify/rules.py` — golden-таблица «серия → группа» (защита от дрейфа порогов)

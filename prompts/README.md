# Промпты

Пусто (ИИ подключается с Ф2 опционально).

Правило: **промпт живёт в файле, не в f-строке в коде.** Промпт это контент —
его правят, ревьюят и версионируют отдельно от логики, поэтому на inline-промпты
ставится коммит-гейт.

Планируемые файлы:
- `niche_detect.md` — определение ниши домена по главной странице (Ф2)
- `case_narrative.md` — абзац текста кейса строго по переданным числам (Ф3)
- `growth_hypothesis.md` — гипотеза «почему выросло», черновик для специалиста (Ф3+)
- `case_selfcheck.md` — сверка текста кейса с числами перед публикацией (Ф4)

В каждом промпте про кейсы — жёсткий запрет утверждать, какие работы велись
на проекте: этих данных у модели нет.

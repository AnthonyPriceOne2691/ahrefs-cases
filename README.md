# Ahrefs Cases

Сервис автоматической генерации SEO-кейсов из динамики Ahrefs.

Вход — список сайтов с периодом работ. Сервис забирает из Ahrefs API v3 историю по
каждому домену (органический трафик, распределение позиций, ссылочный профиль),
раскладывает проекты на группы по динамике и по успешным собирает готовый
PDF-кейс: точка А → точка Б, графики роста, ключевые метрики.

```
список проектов (XLSX / Google Sheet) → сбор истории из Ahrefs
   → классификация (good / medium / poor / insufficient_data)
   → генерация кейса (A→B, графики, PDF) → ZIP
```

**Статус: каркас.** Кода нет — модули объявлены стабами с описанием темы каждого.

## Архитектура

Ядро не знает про веб. Сбор, классификация и сборка кейса — библиотека, у которой
на входе данные и на выходе данные; FastAPI, очередь задач и фронт — обвязка
вокруг неё. Ядро тестируется без сервера и без сети, а любая часть обвязки
заменяется, не задевая расчёты.

```
src/ahrefs_cases/
├── intake/      чтение XLSX и Google Sheet, валидация, нормализация доменов
├── collect/     Ahrefs: транспорт, спеки endpoint'ов, кэш, бюджет, квота, журнал
├── classify/    точки А/Б, дельты, пороги, вердикт
├── cases/       сборка кейса, highlights, текст
├── export/      HTML-шаблон, SVG-графики, PDF, ZIP
└── storage/     модели, репозитории
```

## Экономия units — не оптимизация, а требование

Ahrefs API оплачивается поштучно (units), и прогон по сотне доменов способен
выжечь месячную квоту. Поэтому экономия встроена в конструкцию слоя `collect`:

- **закрытые месяцы истории неизменяемы** — собранный январь не запрашивается
  повторно никогда; повторный прогон догружает только новые месяцы;
- **двухступенчатая воронка** — трафик всем проектам, остальные метрики только
  кандидатам в кейсы;
- **минимальный `select`** — каждое лишнее поле в history-запросе платное;
- **месячная группировка** вместо дневной: биллинг идёт за строки;
- **смета до запуска** и мягкий стоп по остатку квоты;
- **фактические `x-api-units-cost-*`** пишутся в журнал по каждому запросу.

Разбор endpoint'ов и их стоимости — [docs/RESEARCH_AHREFS_API.md](docs/RESEARCH_AHREFS_API.md).

## Стек

Python 3.12 + FastAPI + Pydantic v2, PostgreSQL + SQLAlchemy 2 + Alembic,
Redis + RQ, фронт React + Vite. Экспорт: Jinja2 → WeasyPrint, графики — SVG с
бэкенда (один файл идёт и в PDF, и на страницу).

## Разработка

Доступ к Ahrefs спрятан за интерфейсом провайдера: `fixture` (записанные и
синтетические ответы) и `live`. Выбор конфигом, не кодом — разработка и тесты
идут без ключа, без сети и без расхода квоты.

```bash
cp .env.example .env     # ключи не нужны: провайдер по умолчанию fixture
```

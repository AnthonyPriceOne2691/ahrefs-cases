# Инварианты

1. **Колонок десять обязательных и две необязательных**, имена латиницей:
   `domain`, `period_start`, `period_end`, `niche`, `geo`, `service_type`,
   `work_volume`, `client`, `owner`, `publishable`; `target_mode`, `notes`.
   Регистр и пробелы по краям прощаются, остальное — нет: `Period Start` не
   `period_start`, отказ только подсказывает ближайшее имя. Правило
   соответствия имён одно (`rows.normalize_columns`).
2. **Два брака — два последствия.** Чего нет в **шапке**, того нет ни в одной
   строке: нет колонок, строк нет вовсе, одна шапка, колонка дважды, книга не
   читается, двоичный файл под именем `.csv` — отказ целиком, `400` на HTTP и
   код 2 в командной строке, в базе ничего. Чего нет в **ячейке** — брак
   строки: отчёт `200` с номером строки и причиной, годные строки приняты.
   Ответ «принято 0» над негодным файлом — ложь успехом (так же, как страница
   входа закрытой таблицы, урок L10).
3. **Пустое там, где разрешено не знать, стоит не дороже непонятого.**
   `work_volume` — обязательная колонка с ячейкой, которую можно оставить
   пустой; непонятая ячейка — замечание, строка принята (урок L67).
4. **Лист выбирается, а не ищется.** Книга — первый лист, таблица по ссылке —
   лист из `gid`. Список на другом листе — брак файла, и отказ называет
   прочитанный лист и остальные.
5. **Подсказка экрана и приём говорят одно.** Колонки с примерами, форматы
   файла и предел в 2 МБ живут данными (`listFormat.json`), общими для обеих
   подсказок и фильтра выбора файла; `tests/test_intake_list_format.py` сверяет
   их с константами приёма, читая оба места.
6. **Предела числа строк у приёма нет.** «До 100 проектов за загрузку» из ТЗ —
   объём, а не правило: смета и прогон считают всю базу, второй файл предел
   на загрузку обходит. Траты держит смета с квотой.
